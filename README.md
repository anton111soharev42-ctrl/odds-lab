# Odds Lab

Калькулятор шансов для покера (Texas Hold'em), блэкджека и счёта карт Hi-Lo.

## Установка

**iPhone / любой телефон (веб-версия):** открой ссылку на GitHub Pages в Safari → «Поделиться» → «На экран „Домой“».
Работает как приложение и офлайн.

**Android:** скачай `OddsLab.apk` из раздела Releases и установи (разреши установку из неизвестных источников).

## Что умеет

- **Покер** — эквити руки (точный перебор хедз-ап на флопе/тёрне/ривере, Монте-Карло в остальных случаях),
  диапазоны соперников, шансы банка и EV колла, ауты, вероятности итоговых комбинаций, рейтинг стартовой руки.
- **Блэкджек** — EV каждого действия по реальному составу шуза (composition-dependent), отклонения от базовой
  стратегии по счёту, страховка / even money, распределение итогов дилера, настраиваемые правила стола.
- **Счёт карт** — Hi-Lo: текущий и истинный счёт, оценка перевеса, размер ставки и Келли, состав остатка шуза.

> Для обучения и разбора раздач. Использование подсказок и счёта карт во время игры обычно запрещено правилами казино и покер-румов.

## Структура

- `app/` — Android-приложение (Kotlin, Jetpack Compose). Сборка: `./gradlew assembleRelease`, тесты: `./gradlew testDebugUnitTest`.
- `docs/` — веб-версия (PWA), публикуется через GitHub Pages.
